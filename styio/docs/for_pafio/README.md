# For Pafio Docs

**Purpose:** Define the Styio-owned compiler handoff consumed by Pafio; the generated inventory lives in [INDEX.md](./INDEX.md).

**Last updated:** 2026-07-30

## Scope

1. Record only Styio machine contracts that Pafio consumes.
2. Keep Pafio project, dependency, packaging, and publish-client behavior in
   the Pafio repository.
3. Keep registry service and hosted execution behavior in Styio Platform.
4. Do not add compiler installation, selection, pinning, updating, or caching
   behavior to this handoff.

## Naming Rules

Use one descriptive document per current public contract. Retired migration
plans and compatibility-era coordination notes are recovered from version
control rather than preserved as active handoff documents.
