# All-In-One Docs

This directory contains root-level rollups for the combined Styio and Vityo workspace.

The imported Styio hygiene gate is executed from this repository root in CI. Its referenced maintenance entrypoints live under the imported Styio module:

- `scripts/docs-index.py` maps to `styio/scripts/docs-index.py`.
- `scripts/docs-lifecycle.py` maps to `styio/scripts/docs-lifecycle.py`.
- `scripts/docs-audit.py` maps to `styio/scripts/docs-audit.py`.
